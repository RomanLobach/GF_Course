Ваше завдання — попрактикуватися зі створенням FreeRTOS tasks та передачею подій між ними через Queue.

Що потрібно зробити

Створіть програму з:

Головним циклом — він отримує через чергу результати обробки натискання кнопки та запускає відповідну відправку повідомлення по радіо.Окремою задачею для кнопки — вона має визначати тип натискання:одинарне;подвійне.Після визначення типу натискання задача передає результат у Queue.одинарне;подвійне.Окремою задачею для радіо — вона відповідає за відправку повідомлень по радіо.

Логіка роботи

Програма має працювати за такою схемою:

Кнопка → Button Task → Queue → Main Loop → Radio Task → радіоповідомлення

Головний цикл отримує з черги готовий результат натискання і залежно від нього запускає відправку одного з двох різних пакетів.

Наприклад:

одинарне натискання → BUTTON SINGLEподвійне натискання → BUTTON DOUBLE

Текст повідомлень можете обрати самостійно.

Важливо

Не виконуйте всю логіку в одному loop(). Завдання полягає саме в тому, щоб рознести незалежні частини роботи по окремих tasks і передавати між ними події через Queue.

Зверніть увагу на:

створення та запуск FreeRTOS tasks;роботу з Queue;пріоритети задач;відсутність зайвого блокування;коректну передачу події від однієї задачі до іншої.

⭐ Завдання із зірочкою

Додайте вимірювання часу від моменту натискання кнопки до моменту відправки відповідного радіоповідомлення.

Зафіксуйте отримане значення та коротко опишіть, де у вашій програмі виникає затримка.

Для вирішення завдання будуть використані дві плати lilygo ttgo t3 esp32 LoRa v1.6.1

Основний пристрій - передавач використовуватиме дані з gps модуля (SEQURE M10-25Q) для передачі.
Через нестабільний прийом gps сигналу в місті Запоріжжя передавати буду не координати, а дату та час.

Обидва пристрої: передавач та приймач, мають підключену кнопку.

Піни, які використовуються у обох пристроях:
button - GPIO39

Підключення gps до передавача:
GPS_UART_RX - GPIO15
GPS_UART_TX - GPIO14

Hardware ID приймача: /dev/cu.usbserial-59260139821
Hardware ID передавача: /dev/cu.usbserial-58EF0800971
